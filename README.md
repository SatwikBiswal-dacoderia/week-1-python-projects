My first three Python projects, built while learning programming fundamentals.

## Projects

### 1. Calculator
Performs basic arithmetic operations.

### 2. Number Guessing Game
A game where the user guesses a randomly generated number.

A multiple-question quiz that tracks the user's score.

## Concepts Practiced
- Variables and data types
- Input and output
- Conditional statements
- Loops
- Lists and dictionaries
- Basic problem-solving

## How to Run
Install Python 3, open a terminal in this folder, and run any project:

`python calculator.py`

Replace `calculator.py` with the filename of another project to run it.
